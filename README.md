## Jak to funguje

### Učitel (příprava testu)
1. Otevři rozcestník a vyber předmět a ročník
2. Nastav: třídu, počet variant, datum, PIN, počet otázek a tematické okruhy
3. Klikni **Vygenerovat online test** → stáhne se soubor `.html`
4. Sdílej soubor studentům (Google Classroom, email, odkaz)

### Student (vyplnění testu)
1. Otevři soubor v prohlížeči (Chrome doporučen)
2. Zadej jméno a variantu (přidělí učitel)
3. Vyplň odpovědi a klikni **Odevzdat**
4. Stáhne se hodnotící soubor `hodnoceni_Jmeno_datum.html`
5. Nahraj ho do Google Classroom jako odevzdání

### Učitel (hodnocení)
1. Stáhni hodnotící soubor z Classroom
2. Otevři v prohlížeči → klikni **Zadat PIN** → zadej PIN
3. U každé otázky vyplň **Body** a **max** (max bodů za otázku)
4. Systém automaticky spočítá % a navrhne známku
5. Uprav hodnocení a přidej komentář
6. Klikni **Tisk / PDF** → uložit jako PDF → nahraj zpět studentovi

## Technické poznámky

- Vše běží v prohlížeči, žádný server není potřeba
- Data se nikam neposílají, vše je lokální
- Doporučený prohlížeč: **Chrome** (Edge může mít problémy se stahováním)
- Funguje na PC, tabletu i mobilním telefonu
